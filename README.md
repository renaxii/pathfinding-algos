# pathfinding algorithms
A pathfinding visualizer built with Python and Pygame. Create obstacles on a grid and see how different pathfinding algorithms navigate from a starting point to a destination.

## instructions
- Drag to change start or end points
- Left-click or drag to add walls
- Right-click or drag to remove walls
- Spacebar to run algorithm
